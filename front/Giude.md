# Визуализация данных для проекта хиральных сред

Скрипт читает `input.json` (результаты расчетов из C#) и строит интерактивные графики через Plotly.

## Что строит
- `cd_2d.html` — три графика дихроизма (Δε, ΔA, θ).
- `ord_2d.html` — оптическое вращение.
- `combined.html` — CD и ORD вместе, две оси Y.
- `surface_3d.html` — трехмерный график θ(λ, c).
