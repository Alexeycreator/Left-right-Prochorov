# Описание работы приложения

Данное приложение — WinForms-интерфейс на C#, который собирает параметры оптически активной (хиральной) среды, выполняет все физические расчёты и сохраняет готовый JSON-файл с массивами точек для построения графиков (в Python, Excel или онлайн-редакторе).

Приложение не рисует графики само. Оно выступает в роли **«толстого вычислителя»**, полностью подготавливая данные для визуализации.

## Принцип работы

1. Пользователь заполняет поля и таблицу полос.
2. При любом изменении данных обновляется лёгкий предпросмотр (без тяжёлых расчётов).
3. По нажатию «Сформировать JSON»:
   - запускается полная валидация;
   - вызывается `PhysicsCalculator.CalculateFullSpectrum`;
   - результат сериализуется в `input.json` (папка `Data/`);
   - пользователь видит путь к сохранённому файлу.

## Этапы работы

### 1. Инициализация формы

В конструкторе `MainForm`:
- вызываются `SetupComboBoxes` и `SetupLanesGrid`;
- подписываются обработчики `ValueChanged` / `CheckedChanged` на лёгкий предпросмотр;
- заполняется правая панель с формулами (`rtb_formulas.Text = AppConfig.FormulasText`).

### 2. Лёгкий предпросмотр

Метод `UpdatePreviewLight` собирает данные из контролов и выводит их в нижнюю таблицу `dgv_preview`. **Тяжёлых вычислений здесь нет**, поэтому ввод чисел не вызывает зависаний.

### 3. Валидация

Перед расчётом все значения передаются в `DataValidator.ValidateAll`. Каждая проверка возвращает `bool` и текст ошибки. Если проверка не пройдена — `MessageBox` с `Icon.Warning` и выход без расчёта.

### 4. Расчёт

`PhysicsCalculator.CalculateFullSpectrum` выполняет:

- **Сетка длин волн:** `λ_i = λ_min + i·Δλ`, `i = 0..N-1`. Защита от «бесконечного» цикла — через `decimal` и `MaxPointsLimit`.
- **Δε(λ):** сумма гауссовых или лоренцевых полос с учётом знака среды (`sign = ±1`).
- **ΔA и θ:** `ΔA = Δε·c·l`, `θ = 32980·ΔA`.
- **ORD:** дискретное преобразование Крамерса — Кронига:
  ```text
  φ(λ_i) ≈ (2/π)·Σ_{j≠i} λ_j·Δε(λ_j)/(λ_j²−λ_i²)·Δλ
  ```
- **3D-данные:** та же формула эллиптичности для трёх концентраций (`0.5c`, `c`, `1.5c`), чтобы можно было построить поверхность.

### 5. Сериализация

`JsonService.SaveInput` создаёт папку `Data`, если её нет, и сохраняет `input.json` через `System.Text.Json` с отступами (`WriteIndented = true`). Ошибки записи ловятся и показываются пользователю.

## Что попадает в JSON

| Блок | Содержимое |
|---|---|
| `task` | тип расчёта (`ord_from_params`, `cd_from_params`, `cd_to_ord_kramers_kronig`) |
| `experiment` | диапазон, шаг, толщина, концентрация, путь, молярная масса |
| `medium_model` | знак среды, тип полос, массив полос |
| `output` | хочу ли JSON/PNG, единицы вывода |
| `results` | **готовые массивы** для графиков: `wavelength`, `delta_epsilon`, `delta_a`, `ellipticity`, `optical_rotation`, `surface_3d` |

## Устойчивость и защита

- **Защита UI от зависаний:** тяжёлые расчёты вынесены из `ValueChanged` в кнопку; кнопка блокируется на время расчёта.
- **Защита от переполнения:** `MaxPointsLimit = 10000` в `PhysicsCalculator`, `MaxGridPoints = 100000` в `AppConfig` (валидация).
- **Точность сетки:** вместо накопления `double` используется `decimal` + целочисленный индекс (`λ_i = λ_min + i·Δλ`).
- **Обработка ошибок:** все файловые операции и парсинг таблицы обёрнуты в `try/catch` с показом `MessageBox` (`Icon.Error`).

## Схема вычислений (формулы)

```text
Δε(λ)  = Σ A_k · exp(−(λ − λ_k)² / (2σ_k²))       [гаусс]
Δε(λ)  = Σ A_k · γ_k² / ((λ − λ_k)² + γ_k²)       [лоренц]
ΔA(λ)  = Δε(λ) · c · l
θ(λ)   = 32980 · ΔA(λ)
φ(λ_i) = (2/π) · Σ λ_j·Δε(λ_j)/(λ_j² − λ_i²) · Δλ
```

## Что можно подключить дальше

- **Python-скрипт** `plot_builder.py`, который читает `input.json` и сохраняет `plot.png` (Matplotlib / Plotly).
- **Онлайн-визуализатор** (например, DATIK или Python Explorer) — для быстрой проверки кривых.
- **Экспорт в CSV** — если нужно открыть данные в Excel.
- **3D-визуализация** — `surface_3d` из JSON напрямую подходит для `plot_surface` в Matplotlib или `scatter3d` в Plotly.

## Ограничения

- WinForms работает только на Windows.
- Модель использует параметризованные полосы, а не квантово-химический расчёт.
- Крамерс — Кронига считается в дискретном приближении; точность зависит от диапазона и шага сетки.
