# Описание работы приложения

Данное приложение разделено на два независимых слоя. Первый слой — WinForms-интерфейс на C#, который собирает параметры оптически активной (хиральной) среды и выполняет все физические расчёты. Второй слой — Python-скрипт, который читает готовые данные и строит интерактивные графики.

C#-приложение не рисует графики само. Оно выступает в роли **«толстого вычислителя»**, подготавливая данные для визуализации.

## Принцип работы

1. Пользователь заполняет поля и таблицу полос в C#.
2. При любом изменении данных обновляется лёгкий предпросмотр (без тяжёлых расчётов).
3. По нажатию «Сформировать JSON»:
   - запускается полная валидация;
   - вызывается `PhysicsCalculator.CalculateFullSpectrum`;
   - результат сериализуется в `input.json` (папка `Data/`).
4. Пользователь запускает скрипт `plot_builder.py`.
5. Python читает JSON, строит графики через Plotly и сохраняет их в виде интерактивных HTML-файлов.

## Этапы работы C# (WinForms)

### 1. Инициализация формы
В конструкторе `MainForm` настраиваются ComboBox и DataGridView, подписываются обработчики на лёгкий предпросмотр, а также заполняется правая панель с формулами.

### 2. Лёгкий предпросмотр
Метод `UpdatePreviewLight` собирает данные из контролов и выводит их в нижнюю таблицу `dgv_preview`. **Тяжёлых вычислений здесь нет**, поэтому ввод чисел не вызывает зависаний.

### 3. Валидация
Перед расчётом все значения передаются в `DataValidator.ValidateAll`. Если проверка не пройдена — `MessageBox` с `Icon.Warning` и выход без расчёта.

### 4. Расчёт
`PhysicsCalculator.CalculateFullSpectrum` выполняет:
- **Сетка длин волн:** `λ_i = λ_min + i·Δλ`, `i = 0..N-1`.
- **Δε(λ):** сумма гауссовых или лоренцевых полос с учётом знака среды (`sign = ±1`).
- **ΔA и θ:** `ΔA = Δε·c·l`, `θ = 32980·ΔA`.
- **ORD:** дискретное преобразование Крамерса — Кронига.
- **3D-данные:** расчет эллиптичности для трёх концентраций.

### 5. Сериализация
`JsonService.SaveInput` создаёт папку `Data` и сохраняет `input.json` через `System.Text.Json` с отступами. Ошибки записи ловятся и показываются пользователю.

## Этапы работы Python (Визуализация)

### 1. Чтение данных
Скрипт `plot_builder.py` открывает `input.json` и проверяет наличие блока `results`, в котором лежат уже готовые массивы точек.

### 2. Построение графиков (Plotly)
Для каждого типа визуализации создается свой объект `go.Figure`:
- **2D CD:** строится с помощью `make_subplots` (3 графика в ряд).
- **2D ORD:** строится график оптического вращения с горизонтальной нулевой линией.
- **Combined:** используется `make_subplots(specs=[[{"secondary_y": True}]])` для совмещения CD (левая ось) и ORD (правая ось).
- **3D Surface:** используется `go.Surface` для отрисовки матрицы `z_ellipticity` в координатах длины волны и концентрации.

### 3. Сохранение
Каждый график сохраняется в формате HTML (`fig.write_html`). Благодаря подключению Plotly через CDN, HTML-файлы получаются легкими, открываются в любом браузере и поддерживают интерактивность (масштабирование, наведение курсора, вращение 3D).

## Что попадает в JSON

| Блок | Содержимое |
|---|---|
| `task` | тип расчёта |
| `experiment` | диапазон, шаг, толщина, концентрация, путь, молярная масса |
| `medium_model` | знак среды, тип полос, массив полос |
| `output` | хочу ли JSON/PNG, единицы вывода |
| `results` | **готовые массивы:** `wavelength`, `delta_epsilon`, `delta_a`, `ellipticity`, `optical_rotation`, `surface_3d` |

## Устойчивость и защита

- **Защита UI от зависаний:** тяжёлые расчёты вынесены из `ValueChanged` в кнопку; кнопка блокируется на время расчёта.
- **Защита от переполнения:** `MaxPointsLimit = 10000` в `PhysicsCalculator`.
- **Точность сетки:** вместо накопления `double` используется `decimal` + целочисленный индекс.
- **Обработка ошибок:** все файловые операции (и в C#, и в Python) и парсинг таблицы обёрнуты в `try/catch`.

## Схема вычислений (формулы)

```text
Δε(λ)  = Σ A_k · exp(−(λ − λ_k)² / (2σ_k²))       [гаусс]
Δε(λ)  = Σ A_k · γ_k² / ((λ − λ_k)² + γ_k²)       [лоренц]
ΔA(λ)  = Δε(λ) · c · l
θ(λ)   = 32980 · ΔA(λ)
φ(λ_i) = (2/π) · Σ λ_j·Δε(λ_j)/(λ_j² − λ_i²) · Δλ
```

## Ограничения

- C# WinForms работает только на Windows.
- Python-скрипт требует установленного Python 3.8+ и библиотеки Plotly (`pip install plotly`).
- Модель использует параметризованные полосы, а не квантово-химический расчёт.
