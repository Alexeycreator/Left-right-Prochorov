# Примеры заполнения полей

Ниже — несколько готовых наборов значений, при которых JSON формируется без ошибок. Можно копировать цифры в интерфейс.

## Что проверяет валидация

- `λ_min > 0`, `λ_max > λ_min`, `Δλ > 0`, `(λ_max − λ_min)/Δλ + 1 ≤ 100000`.
- `Концентрация > 0`, `Длина пути > 0`.
- `Толщина ≥ 0`, `Молярная масса ≥ 0`.
- Хотя бы одна полоса в таблице.
- Выбрана одна из радиокнопок среды.
- Выбран хотя бы один чекбокс вывода.
- ComboBox’ы не пустые.

## Пример 1. Классический спектр CD → ORD

| Поле | Значение |
|---|---|
| Тип задачи | `CD → ORD через Крамерса — Кронига` |
| λ_min | `300` |
| λ_max | `600` |
| Δλ | `1` |
| Толщина | `10` |
| Концентрация | `0.05` |
| Единицы концентрации | `моль/л` |
| Длина пути | `1` |
| Молярная масса | `180` |
| Тип среды | `Правая среда (φ > 0)` |
| Тип полос | `Гауссовы полосы` |
| Полоса λ_k | `450` |
| Полоса σ_k | `20` |
| Полоса A_k | `100` |
| JSON | ✔ |
| PNG | ✔ |
| Единицы вывода | `мград` |

Результат: 301 точка, максимум эллиптичности ≈ 164900 мград, ORD меняет знак вблизи 450 нм.

## Что чаще всего ломает валидацию

| Причина | Как выглядит | Как исправить |
|---|---|---|
| Концентрация = 0 | «должно быть больше нуля» | поставить `0.01` |
| Длина пути = 0 | то же | поставить `1` |
| Пустая таблица полос | «Добавьте хотя бы одну полосу» | нажать «Добавить» |
| Не выбрана среда | «Выберите тип среды» | кликнуть радиокнопку |
| Оба чекбокса вывода сняты | «Выберите хотя бы один формат» | поставить хотя бы один |
| λ_min ≥ λ_max | «λ_min должно быть меньше λ_max» | поменять местами |
| Слишком мелкий шаг | «Слишком много точек сетки» | увеличить Δλ или сузить диапазон |
