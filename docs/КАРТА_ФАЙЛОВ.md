## Файлы C# (WinForms)

### `MainForm.cs`
Главный файл формы. Содержит:
- конструктор, настройку ComboBox и DataGridView;
- обработчики кнопок «Добавить / Удалить / Очистить» полосы;
- лёгкий предпросмотр (`UpdatePreviewLight`) — без тяжёлых расчётов;
- сбор данных из контролов (`CollectInputData`);
- главный обработчик `Btn_calculate_Click` — валидация → расчёт → сохранение JSON.

**Не содержит:** математики, валидации, работы с файлами.

### `MainForm.Designer.cs`
Автогенерируемый файл дизайнера. Содержит объявления всех контролов и метод `InitializeComponent`. Править вручную стоит только при необходимости (например, добавить новый `DataGridView`).

### `DataValidator.cs`
Статический класс со всеми проверками. Каждый метод принимает значения (а не форму) и возвращает `bool` + `out string error`. Используется в `MainForm` перед сохранением.

Методы:
- `IsPositive`, `IsNonNegative` — проверки знака;
- `ValidateWavelengths` — диапазон и количество точек;
- `ValidateTaskAndBands`, `ValidateEnvironment`, `ValidateComboBox`, `ValidateOutput`;
- `ValidateAll` — агрегатор, вызывается один раз из `MainForm`.

### `PhysicsCalculator.cs`
Класс с физическими формулами и главным методом `CalculateFullSpectrum`, который:
1. Строит сетку длин волн.
2. Считает `Δε(λ)` по гауссовым или лоренцевым полосам.
3. Считает `ΔA` и эллиптичность `θ`.
4. Считает ORD через дискретное преобразование Крамерса — Кронига.
5. Формирует 3D-данные (зависимость от концентрации).

Содержит защиту от «бесконечных» циклов (`MaxPointsLimit`) и использует `decimal` для точности сетки.

### `JsonService.cs`
Отвечает только за сериализацию в JSON через встроенный `System.Text.Json` (без внешних библиотек). Создаёт папку `Data/` при необходимости, ловит `UnauthorizedAccessException`, `JsonException` и прочие исключения, оборачивая их в понятные сообщения.

### `AppConfig.cs`
Константы приложения:
- `EllipticityCoefficient = 32980` — перевод `ΔA` → мград;
- `MaxGridPoints = 100000` — ограничение точек;
- имена папки (`Data`), файла (`input.json`);
- текст для панели формул (`FormulasText`).

### `Models/InputDataModel.cs`
POCO-классы для JSON. Каждое свойство помечено `[JsonPropertyName]`, чтобы имена в JSON были на английском (`wavelength_min`, `delta_epsilon` и т.д.), независимо от имён в C#.

Классы:
- `InputDataModel` — корневой объект;
- `ExperimentData`, `MediumModelData`, `BandData`, `OutputData` — блоки параметров;
- `ResultsData`, `Surface3DData` — готовые массивы точек для графиков.

### `Data/input.json`
Файл обмена (создаётся автоматически). Содержит входные параметры и готовые массивы точек для Python-скрипта. Лежит рядом с `.exe`, в подпапке `Data`.

## Файлы Python (Визуализация)

### `plot_builder.py`
Скрипт, который читает `input.json` и строит интерактивные графики через библиотеку Plotly.
- Проверяет наличие файла и блока `results`.
- Создает объекты `go.Figure` для каждого типа графика.
- Сохраняет готовые интерактивные HTML-файлы в папку `plots/` с использованием CDN (для компактности файлов).

### `plots/` (папка с результатами)
- `cd_2d.html` — три графика дихроизма (Δε, ΔA, θ).
- `ord_2d.html` — оптическое вращение (ORD) с нулевой линией.
- `combined.html` — CD и ORD на одном графике с двумя осями Y.
- `surface_3d.html` — трехмерная поверхность θ(λ, c).

## Разделение ответственности

| Файл / Модуль | Что можно | Что нельзя |
|---|---|---|
| `MainForm.cs` | Собирать данные, вызывать сервисы, показывать UI | Считать физику, парсить JSON вручную |
| `DataValidator.cs` | Проверять значения | Показывать MessageBox, работать с контролами |
| `PhysicsCalculator.cs` | Считать формулы | Работать с UI или файлами |
| `JsonService.cs` | Сохранять файлы | Считать физику или валидировать |
| `AppConfig.cs` | Хранить константы | Содержать логику |
| `Models/*.cs` | Хранить структуру | Содержать методы бизнес-логики |
| `plot_builder.py` | Читать JSON, рисовать графики | Выполнять физические расчеты |
