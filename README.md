# Left-Right Optical Media Simulator

Приложение для моделирования оптических свойств «правых» и «левых» (хиральных) сред.

## О чём проект

Тема: **оптически активные среды** — среды, в которых лево- и правополяризованный по кругу свет распространяется с разными фазовыми скоростями и разным поглощением. В результате линейно поляризованный свет, проходя через такую среду, поворачивает плоскость поляризации (оптическое вращение, ORD) и приобретает эллиптичность (круговой дихроизм, CD).

Приложение позволяет задать параметры образца и модельных полос, рассчитать спектры ORD и CD, а также сформировать готовые данные для построения графиков (2D и 3D) в сторонних инструментах (Python, Excel или онлайн-редакторах).

## Что делает приложение

- Принимает параметры эксперимента: диапазон длин волн, толщина образца, концентрация, длина пути, молярная масса.
- Принимает параметры модельных полос: положение, ширина, амплитуда (гауссовы или лоренцевы полосы CD).
- **Выполняет все физические расчёты на стороне C#:**
  - спектр кругового дихроизма (Δε, ΔA, эллиптичность θ);
  - спектр оптического вращения (φ) через дискретное преобразование Крамерса — Кронига;
  - удельное и молярное вращение;
  - данные для 3D-графиков (зависимость от концентрации).
- Валидирует введенные данные перед расчетом (проверка на отрицательные значения, порядок длин волн, лимиты точек и т.д.).
- Формирует `input.json`, который содержит как входные параметры, так и **готовые массивы точек** (`results`), пригодные для прямой отрисовки.
- Приложение само графики не рисует — этим занимается Python-скрипт или любой другой инструмент, читающий JSON.

## Архитектура

```text
┌──────────────────────────┐
│        MainForm          │  <-- интерфейс, события, предпросмотр
│  (MainForm.cs + Designer)│
└────────────┬─────────────┘
             │
   ┌─────────┼──────────────┬───────────────────┐
   │         │              │                   │
   ▼         ▼              ▼                   ▼
┌──────┐ ┌────────┐ ┌───────────────┐ ┌────────────────┐
│Data  │ │Physics │ │  JsonService  │ │   AppConfig    │
│Valid.│ │Calcul. │ │(System.Text.) │ │(константы, пути)│
└──────┘ └────────┘ └───────┬───────┘ └────────────────┘
                            │
                            ▼
                 ┌─────────────────────┐
                 │ Models/             │
                 │  InputDataModel.cs  │
                 │ (структура JSON)    │
                 └──────────┬──────────┘
                            │
                            ▼
                    Data/input.json
```

- **C# WinForms** — ввод параметров, лёгкий предпросмотр, валидация, расчёт спектров, формирование `input.json`.
- **JSON** — единственный протокол обмена. В файл сразу пишутся готовые массивы точек для графиков (`wavelength`, `delta_epsilon`, `delta_a`, `ellipticity`, `optical_rotation`, `surface_3d`).
- **Python (опционально)** — внешний скрипт, который просто читает готовые точки из JSON и отрисовывает графики через Matplotlib / Plotly.

## Технологии и версии

| Компонент | Версия / примечание |
|---|---|
| Платформа | .NET 10.0 (LTS) |
| UI | Windows Forms (WinForms) |
| Язык интерфейса | C# 14.0 (входит в .NET 10 SDK) |
| Обмен данными | JSON (файл `input.json` в папке `Data/`) |
| Сериализация | Встроенный `System.Text.Json` |
| IDE | JetBrains Rider / Visual Studio |

> **Примечание по Python.** Поскольку все расчёты теперь выполняются на C#, Python больше не является обязательным для работы приложения. Если вы планируете использовать Python-скрипт для отрисовки, укажите в этом разделе вашу версию (например, `Python 3.11+` и `matplotlib 3.8+`).

## Требования для запуска

- Windows (WinForms работает только на Windows).
- .NET 10 Desktop Runtime (или SDK, если вы собираете проект из исходников).
- Для просмотра графиков (опционально): любой инструмент, умеющий читать JSON и строить графики (Python-скрипт, Excel или онлайн-редактор).

## Быстрый старт

1. Клонировать репозиторий.
2. Собрать C#-проект (Rider / Visual Studio / `dotnet build`).
3. Запустить WinForms-приложение.
4. Заполнить параметры эксперимента и добавить хотя бы одну полосу в таблицу.
5. Нажать **«Сформировать JSON»**.
6. Забрать готовый файл `Data/input.json` и передать его в скрипт/программу для визуализации.

## Ограничения

- Модель использует параметризованные полосы (гауссовы/лоренцевы), а не квантово-химический расчёт.
- Преобразование Крамерса — Кронига реализуется в дискретном приближении; точность зависит от числа точек и ширины диапазона длин волн.
- WinForms-часть работает только на Windows.
- Приложение не отображает графики внутри интерфейса — только формирует данные для них.
