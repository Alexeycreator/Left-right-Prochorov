# Left-Right Optical Media Simulator

Приложение для моделирования и визуализации оптических свойств «правых» и «левых» (хиральных) сред.

## О чём проект

Тема: **оптически активные среды** — среды, в которых лево- и правополяризованный по кругу свет распространяется с разными фазовыми скоростями и разным поглощением. В результате линейно поляризованный свет, проходя через такую среду, поворачивает плоскость поляризации (оптическое вращение, ORD) и приобретает эллиптичность (круговой дихроизм, CD).

Приложение позволяет задать параметры образца и модельных полос, рассчитать спектры ORD и CD, а также построить графики для отчёта или анализа.

## Что делает приложение

- Принимает параметры эксперимента: диапазон длин волн, толщина образца, концентрация, длина пути.
- Принимает параметры модельных полос: положение, ширина, амплитуда (гауссовы или лоренцевы полосы CD).
- Рассчитывает:
  - спектр кругового дихроизма (Δε, ΔA, эллиптичность θ);
  - спектр оптического вращения (φ) через дискретное преобразование Крамерса — Кронига;
  - удельное и молярное вращение.
- Строит графики (CD и ORD) и сохраняет их в PNG.
- Обменивается данными между интерфейсом (C# WinForms) и вычислительным ядром (Python) через JSON-файлы.

- **C# WinForms** — ввод параметров, формирование `input.json`, запуск Python-скрипта, чтение `output.json`, отображение готового графика.
- **Python** — чтение `input.json`, расчёт спектров по формулам из теории, построение графиков через Matplotlib, сохранение `output.json` и `plot.png`.
- **JSON** — единственный протокол обмена. Никаких прямых вызовов Python-функций из C# и никакой логики интерфейса в Python.

## Требования для запуска

- Windows (WinForms работает только на Windows).
- .NET 10 Desktop Runtime (или SDK, если вы собираете проект из исходников).
- Python (версия, указанная в таблице выше) с установленным Matplotlib.
- Python должен быть доступен в `PATH` (или путь к интерпретатору настраивается в приложении).

## Быстрый старт

1. Клонировать репозиторий.
2. Собрать C#-проект (Rider / Visual Studio / `dotnet build`).
3. Установить Python-зависимости: `pip install matplotlib` (и другие, если используются).
4. Запустить WinForms-приложение.
5. Задать параметры и нажать «Рассчитать и построить».

## Ограничения

- Модель использует параметризованные полосы (гауссовы/лоренцевы), а не квантово-химический расчёт.
- Преобразование Крамерса — Кронига реализуется в дискретном приближении; точность зависит от числа точек и ширины диапазона длин волн.
- WinForms-часть работает только на Windows.
